Ozon Barcode Generator
Простой генератор этикеток для маркетплейса Ozon. Создает PDF-файлы с штрихкодами Code 128, артикулом и описанием товара.
Поддерживает ручной ввод и пакетную генерацию из Excel.

gui.py - Главный файл запуска.
config.ini - Файл настроек этикеток. Здесь хранятся размеры, отступы и шрифты для разных типов наклеек.
generator.py -  Отвечает за создание штрихкодов и рисование PDF.
presets.py - Связующее звено между конфигами и программой. Автоматически подгружает настройки из config.ini.
fonts/ - Папка со шрифтами. Здесь лежат файлы .ttf (например, arial.ttf). Нужны для корректного отображения русского текста.
output/ - Папка результатов. Все созданные PDF-файлы автоматически сохраняются сюда.
app.log - Файл журнала. Сюда записываются все действия и ошибки программы.

Как настроить пресеты этикеток (config.ini)
Файл config.ini позволяет вам создавать свои собственные размеры этикеток без изменения кода программы.
Откройте его через Блокнот или любой текстовый редактор.

[Compact_43x25]
name = Компактная 43x25
label_width_mm = 43.0
label_height_mm = 23.0
margin_top_mm = 0.5
margin_bottom_mm = 0.5
margin_left_mm = 1.0
margin_right_mm = 1.0
barcode_height_mm = 17.0
font_size_code = 7
font_size_desc = 3
module_width = 0.3

Расшифровка параметров
[Compact_43x25] — Техническое имя пресета. Используется внутри программы. Должно быть уникальным, без пробелов и спецсимволов.
name — Отображаемое имя. Именно это название вы увидите в выпадающем списке при выборе размера в программе. Может содержать пробелы и кириллицу.
label_width_mm / label_height_mm — Ширина и высота самой этикетки в миллиметрах.
margin_top/bottom/left/right_mm — Отступы от краев этикетки. Минимальное значение для термопринтеров обычно 0.5–1 мм. Если сделать 0, принтер может обрезать края.
barcode_height_mm — Высота штрихкода. Чем выше, тем легче сканировать. Для маленьких этикеток оптимально 15–20 мм.
font_size_code — Размер шрифта артикула (цифры под штрихкодом). Для мелких этикеток используйте 6–8 pt.
font_size_desc — Размер шрифта описания товара. Для этикеток 43x25 мм оптимально 3–4 pt.
module_width — Толщина одной полоски штрихкода.
0.2 — тонкие линии (компактно, но требует хорошего принтера)
0.3 — стандартная толщина (рекомендуется)
0.4+ — жирные линии (занимают много места, но максимально надежно сканируются)

Как добавить новый пресет
Откройте config.ini.
Скопируйте любой существующий блок целиком (от [...] до последнего параметра).
Вставьте его ниже.
Измените техническое имя в квадратных скобках (например, [My_New_Preset]).
Измените name на понятное вам название.
Поменяйте размеры (width, height) и остальные параметры под ваш принтер.
Сохраните файл (Ctrl+S) и перезапустите программу. Новый пресет появится в списке автоматически!
